# Simple C# Hangman Game

 very simple Hangman game in C# using a console app.

## 1. Create the project

 a `hangman` project folder, 

```terminal
dotnet new console -n hangman


## 1. Game idea

- `words` contains the possible secret words.
- `secret` is the chosen word for one round.
- `guessed` stores letters the player already tried.
- The game prints `_` for letters not yet guessed.
- Correct guesses are revealed in the word.
- `wrong` counts incorrect guesses.
- The game ends when the player wins or reaches 6 wrong guesses.


#

A simple Hangman game built in C# using basic console input/output.
The project contains three connected files:

- `Program.cs` – starts the game
- `WordList.cs` – contains the list of words
- `HangmanGame.cs` – contains all game logic

This project is perfect for beginners learning:

- loops
- arrays
- classes
- methods
- random word selection
- console drawing
